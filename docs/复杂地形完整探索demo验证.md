## 扩图后旧障碍附近新纳入格漏派生

先观测上述宽墙，再从 `(0,9,π)` 发布真实西向地面观测，未额外测量墙面或阴影。raw/fine/guidance 版本与两层输出时间戳均已更新、bounds 已扩展，但旧前缘下方 y=6.1 一行保持 UNKNOWN，使同一粗格仍 UNKNOWN；仅扩展 bounds 并不自动重新派生这些格。修复前集成测试把该条件保留为 strict xfail，输入、版本、阴影等前置条件失败仍会正常报错。

独立最小 C++ 复现 `/tmp/integrated-explorer-fine-growth-review.json` 进一步排除传感器与 DDS：只新增远处 1 个 ground 格，旧阻塞高程保持不变；对同一最终 raw snapshot，新增范围中距旧阻塞面 0.2 m 的未观测格，incremental=UNKNOWN、full=BLOCKED、直接 FineCellEvaluator=BLOCKED，共 5 格不一致。原因是增量构建仅更新新高程的影响范围，geometry 扩展后旧障碍影响范围内新纳入的格没有被派生。

修复在当前稀疏 CandidateTiles 中计算新旧 bounds 差集，补入现有 recompute 集合；复用 evaluator、不可变瓦片共享和 changed_halo_tiles，不填 raw，不修改 coarse 规则，不在每次扩图时退回全图重算。六个方向/角落、merged changes 入口、超过一万亿逻辑格但仅少量已分配瓦片的回归均通过；独立复现差异由 5 格降为 0。独立代码审查未发现阻断项，扩图仍会遍历已分配候选瓦片，不宣称只按 changed_cells 的数量工作。
