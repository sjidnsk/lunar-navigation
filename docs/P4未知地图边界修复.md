# P4 保留输入地图的未知边界

2026-09-17，接续 `fix/wheel-terrain-basic`。仅修改 P4 地图处理及其既有派生流水线，不修改 P3、地图话题、车辆能力或起点补偿半径。

## 行为

- 内部高程地图范围包含 P3 输入的完整矩形，包括全为 NaN 的边界。变换后使用输入矩形参考平面四角的轴对齐包围框；有效三维高程点必要时继续扩展范围。
- 同一坐标系下滚动输入的范围取历史并集，保留既有持久地图语义。未知更新不会删除已有有限高程。
- 首次全 NaN 输入也建立有效几何范围；不分配高程 tile、不填造高度。相同范围/相同观测重复输入不增加 revision。
- 仅边界扩大时也增加 raw revision；高度 changed_cells/dirty_tiles 可以为空。
- ROS 派生流水线按原始快照是否更新判断待处理工作，不再把“没有高程脏格”误当“没有地图变化”。边界更新继续传递给细地图和粗引导图。
- 无高度变化的多个 revision 不伪造 changed_cells；不能使用原有非空合并变更合同的情形走已有完整派生分支。有限观测变化仍保留原有合并增量更新。
- UNKNOWN 仍不可直接通行；已有起点补偿仅在观测支持、距离和可达出口满足时建立请求内假设，不修改原始地图。
- 局部细地图显示仍使用原有 28×28 m 窗口；全局/探索范围保留完整输入范围。扩大未知地图框不等于扩大传感器观测范围。
