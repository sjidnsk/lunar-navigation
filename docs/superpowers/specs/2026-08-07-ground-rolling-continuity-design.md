# 地面平台滚动预取、双缓冲与连续插值设计

日期：2026-08-07

状态：已按用户“前面的推荐修复也一并处理”授权冻结

## 1. 已确认问题

当前测试执行器以“总时长比例乘样本数量”选择轨迹区间，忽略每个 ROS trajectory point 的
`time_from_start`；姿态四元数逐分量线性插值后再归一化。局部段结束才默认请求下一段，且返回的
下一段会直接替换活动引用。因此即使核心路径几何正确，也会出现速度不均、偏航抖动、段尾停顿或
回跳。用户界面使用大于 1 的时间倍率时会进一步放大这些现象。

## 2. 时序和姿态合同

`GroundReference` 保存与样本一一对应、从 0 开始且严格递增的 `sample_times_s`。转换 ROS 引用时：

- 优先保留 `time_from_start`；
- 若消息全为零，才按累计弧长和配置速度生成时间；
- 若真实规划起点缺失，在 0 秒插入该起点；
- 非单调、重复的非零时间或非有限值 fail closed。

执行器用二分查找定位当前时间区间。位置和线速度线性插值；姿态使用归一化最短弧 SLERP，点积为负
时翻转第二个四元数，近共线时使用归一化线性退化。剩余距离由“当前插值点到下一样本 + 后续折线”
计算，不再用总弧长乘剩余时间比例估算。

## 3. 1 倍速和提前请求

RViz 启动脚本与节点默认 `ground_execution_time_scale=1.0`；更快倍率保留为显式测试选项，不用于
可视化验收。

预取以真实轨迹剩余时间为主，默认 lead time 为 3 秒；已有
`ground_replan_remaining_m` 作为额外的距离触发条件。只要当前段不直接到最终目标、没有在途请求且
任一阈值满足，就发出 `PLAN_NEXT`。在轮式 Release 局部 p95 不超过 2 秒后，默认至少留 1 秒拼接裕度。

## 4. 双缓冲和拼接

滚动会话同时维护一个活动引用和至多一个待切换引用：

1. `PLAN_NEXT` 捕获不可变的 request start pose；ROS 结果按该 pose 转换，不能按结果到达时已经移动的
   当前 pose 伪造新起点。
2. 下一引用在当前段执行期间返回时进入 `NEXT_READY`，不得替换活动引用或把平台拉回旧起点。
3. 当前段结束时，在待切换折线上按前向顺序寻找与实际段尾最近的样本/线段。只有位置、偏航和速度
   分别满足 `0.05 m`、`5 deg`、`0.10 m/s` 连续性时才裁掉已执行前缀并切换。
4. 拼接首点使用实际段尾状态，后续点和时间仅做前缀平移；不创造跨越障碍的新线段。找不到合法交点
   时丢弃缓存，保持段尾并立即从规范里程计重新规划。
5. 预取失败不会把仍有效的活动引用报告为执行故障；当前段继续。段尾若仍无下一引用，再进入
   `PLANNING_NEXT` 保持。

每个切换仍发布 `SEGMENT_COMPLETE`，下一段接受发布新的 `ACCEPTED/EXECUTING`；旧 plan 的反馈不会在
新 plan 上复用。取消、平台切换和新最终 Goal 同时清空活动/待切换引用。

## 5. 局部地图更新抖动

测试桥不再每移动一个 0.2 m 栅格就重编码十个局部图层。局部窗口采用中心保留区：平台离当前窗口
中心超过 `max(2 * resolution, 0.25 * half_extent)`，或下一规划起点将离开安全核心时才重心化。
未重心化期间复用已编码局部 GridMap 与 hazard cloud；规范里程计仍以 10 Hz 更新，不冻结平台状态。

## 6. 测试与验收

- 非等间隔时间样本在正确时间区间插值；剩余弧长单调；SLERP 单位范数且正确跨越 `179/-179 deg`。
- 预取结果先进入 buffer；活动 pose 在结果回调时不倒退；合法拼接位置/速度/偏航连续；不合法拼接
  触发安全重规划。
- wheel 和 legged 均覆盖“当前段执行中 -> 下一段返回 -> 无停顿切换 -> 最终完成”。
- RViz 真实进程以 1 倍速录制，平台相邻 Marker 位移、速度和偏航无段边界突跳；显式快进模式不作为
  丝滑性资格证据。
- 局部图窗口在中心保留区内 generation 不变，越界时恰好更新一次，并保持平台位于新窗口内部。

本设计只改变仓库外测试执行与地图发布节奏，不伪造核心认证，不修改三类平台能力参数。
