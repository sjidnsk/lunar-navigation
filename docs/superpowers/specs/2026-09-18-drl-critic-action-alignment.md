# 探索 Critic：候选位置对应与定向剩余观测特征

状态：2026-09-19 用户确认并授权实施；正式代码已接入训练与推理协议，验证见[实施记录](../../validation/2026-09-19-drl-graph-critic-implementation.md)。旧模型迁移、长期效果消融尚未执行。

## 1. 范围与动机

继承 `2026-09-18-drl-decision-graph-consolidated.md` 的节点、连边和动作语义。
只讨论训练侧 Critic 的特权输入及读取方式。Actor 继续接收测量图、任务多边形与平台/传感器上下文，动作仍为相邻位置与八个朝向。
不增加任务距离场、入区阶段、接近奖励、访问黑名单或零收益动作屏蔽。区外站位可以观测任务内部，区外路径可以承担必要转移。

参考论文的成熟部分是非对称 SAC，以及对同一组动作读取其在真值图上的对应特征。
项目需要适配增量节点、实际位姿、90° 视野和真实导航闭环。当前公共真值摘要不是已证实的循环根因；本设计降低表示负担，不声称直接解决收敛或所有循环。

主要依据：

- [RA-L 2024 论文 IV-C](https://arxiv.org/html/2403.10833v1#S4.SS3)。
- [作者 QNet](https://github.com/marmotlab/large-scale-DRL-exploration/blob/main/model.py#L238-L249)。
- [作者同一动作集到真值图的映射](https://github.com/marmotlab/large-scale-DRL-exploration/blob/main/worker.py#L122-L130)。

## 2. 审核后的结构

每个 Critic 独立拥有测量图编码器、真值图编码器及 Q 输出头；不与 Actor 共享权重。
保留现有测量上下文，因为机器人知道什么、平台状态和观测历史都会影响其后续决策。

```text
测量图、任务、平台、候选动作 → 测量动作特征 z(o,a) ───────────┐
静态真值骨架 + 当前已观测状态 → 稀疏图编码 H → 公共上下文 c ─┤
                                               → 位置读取 h(v) ─┤→ Q(o,s*,a)
同一候选位姿在真值二维视域中的静态剩余可见面积 g*(v,θ)/100 ──┘
```

全局上下文保持每个状态一次读取。每个候选位置读取一次 h(v)，八个朝向共享位置结果，分别结合真实目标朝向和 g* 评分。
不为每个动作全图查询，不为八个方向重复编码真值图。双 Critic 与目标网络各有自己的编码，不能在不同网络或更新后的权重间复用学习嵌入。

### 2.1 真值骨架与节点统计

真值骨架仍为训练场景拥有的静态通行图，包含任务外可达通路。
后续正式适配复用已经确认的基础空间覆盖和合法短路径连接规则；不要继续把原生细门户直接当策略尺度。
正式实现由训练侧 `privileged.py` 创建同规则静态骨架，并通过现有 SceneRegistry 共享。

现有参考面积及已观测比例可以继续作为背景空间统计，不把它当作完整环境状态或精确方向可见性。
参考格的区域汇总存在空间压缩；同一比例可能对应不同的剩余分布。本轮的精确 g* 为候选局部补足信息，不证明全局压缩不再有损失。
面积所有权只服务特征汇总，不能用于证明跨墙连通、候选可达或任务耗尽。

### 2.2 只读位置查询，取代双向插入查询节点

上一轮建议把候选作为临时节点插入真值图。本次收紧为：编码稳定真值图后，各候选独立进行只读查询，不反向修改骨架节点特征，也不在查询节点之间连边。

原因：双向插入会使已有候选的特征随其他候选的增删而变化；也会为每个状态增加骨架重编码的结构变化。
只读查询保持几何含义，不要求绝对完整的 Q 对动作集合无关；这里保证的是查询操作不会意外改写其他位置的表示。

对于查询实际位置 v，用原生合法起点连接，沿真值通行图取得局部骨架节点 S(v)，复用空间覆盖半径 r=2 m，而不是增加一个调参半径。
栅格中心查询的读取范围为 r。连续实际位置还可能有接入底层通行图的非零代价 c_min，查询范围应为 r+c_min，其中 c_min 是合法起点连接中的最小代价。这来自已有 r-cover 的几何界，不是新增可调余量；不能从栅格 r-cover 错推连续位置在严格 r 内必有支持。
合法图距离而非直线距离决定读取支持。弯路可以接入，隔墙的直线近邻不能冒充同侧支持。
完整 r-cover 与合法起点连接是非空支持的前提；缺少支持属于表示/适配错误，不应删除 Actor 动作或回退到跨墙最近点。

最简单的读取使用固定几何权重：

`w_i(v)=exp(-d(v,i)/r) / sum_j exp(-d(v,j)/r)`

`h(v)=sum_i w_i(v) H_i`

保留查询实际坐标、支持点相对坐标/距离等几何信息，避免两个不同站位仅因支持相同而被当作同一个点。
无需新增一个候选全局注意力模块。该局部加权只是空间近似，不是原节点特征的精确恢复，也不扩大骨架编码的图感受野。
原型已验证中心站位、八邻接无切角合法图上的支持与读取；正式连续实际位姿的 start_connections 适配仍为 NOT_RUN。

## 3. 定向静态剩余可见面积

精确定义：

`g*_t(v,θ)=resolution² × count(Visible_B*(v,θ,S) ∩ P ∩ E_valid \ K_t)`

- B* 为真值固有二维分类；保持当前不考虑高程视线的决定。
- S 包含量程、水平视角和传感器安装偏航。
- P 为任务多边形，按现有中心栅格包含规则计算。
- E_valid 为高程有限且固有分类非 UNKNOWN 的有效中心测量，保持参考覆盖语义。
- K_t 必须来自该次决策冻结的累计有效已观测状态，不能改用 M==FREE、节点访问标记或执行后的 K_(t+1)。

复用项目 native 有限射线、前缀命中及第一阻挡格语义。第一阻挡格可计入面积，后面遮挡部分不计；平台足迹禁入带不等于实体遮挡。
不以目标格中心方位角再次裁剪命中结果，避免与原生侧接触命中规则不一致。
沿用传感器源栅格量化，不暗中引入另一套亚栅格视域模型；姿态接入通行图仍需保留实际位置。

每个动作得到一个非负 float32 平方米数，在网络入口除以固定 100 m²；不按真值可覆盖总面积归一化，不增加 Actor 可见的分母。
八个方向有重叠，不相加作为一次观测收益或总剩余面积。
离散射线命中的有效格面积可能超过连续扇形的解析面积，不用 πR²×FOV/(2π) 裁剪或断言上限。

### 3.1 不承担的语义

g* 是在动作执行前的 K_t 上，对名义目标位姿执行一次静态观测的特征。
它不是动作真实奖励、预计总收益、导航成功概率或动作可用性。

- 沿途移动和转向可能看到终点视野之外的区域。
- 沿途可能已经观测了终点静态特征中的格子。
- 实际到达位置/朝向容差可能改变终点视野。
- g*=0 的动作可以是必要回退、长通道转移或区外绕行。

因此不加入 `Q=g*+固定规则`，不把 g* 当 TD 标签，不用 g*=0 屏蔽动作，也不因它判断任务耗尽。

## 4. 数据、时序与存储职责

环境侧拥有真值栅格与原生传感器接口，负责生成训练专用描述。
在线图模块、TaskAnalyzer、Actor、导航器不依赖这个描述。

在一次决策快照上：

1. 冻结测量观测 o_t、动作列表及 K_t。
2. 训练侧为全部合法候选生成只读位置支持与 g*_t；不能只保存被选择动作，因为 SAC Actor 更新评价全部候选。
3. 执行动作，真实观测/路程/转角计算 r_t。
4. 为下一快照单独生成 o_(t+1)、K_(t+1)、g*_(t+1)。

位置支持按唯一位置共享给各朝向，g* 按冻结动作序保存。对动作排序、同位不同朝向、批次场景偏移必须保持一致。
原地转向仍是当前真实位置的一个动作；若已终止且没有动作，下一个描述可为空，沿用终止语义而不制造动作。

推荐在采集侧算一次、回放保存标量与紧凑的静态节点索引/距离，不在每个梯度更新中重跑所有射线。
骨架由场景注册表共享。中间可见格集合仅用作瞬时计算；不保存每个动作的可见位图，不复制整张真值地形到每条经验，不保存学习嵌入到回放。
可缓存几何支持，但缓存归属场景并随场景释放；不建立无上限的全历史站位缓存。

当前＋下一状态的 g* 仅增加 `4×(A_t+A_(t+1))` 字节。例如两端各 128 个动作为 1024 字节；10 万条约 97.7 MiB。
这是标量部分，不包含几何支持、Python 容器或序列化开销。冻结相邻状态共享可以减少重复，但不能把它当作已实现压缩。

## 5. 学习契约与兼容

沿用双 Critic、目标网络、Actor 分布和当前 SAC 目标：

`y=r + γ(1-terminated) Σ_a' π(a'|o') [min(Q1_target,Q2_target)(o',s*',a') - α log π(a'|o')]`

下一步动作只能来自下一次 Actor 的测量候选列表；不从真值图增加捷径，不用真值最短路替代实际导航转移。
预算截断继续 bootstrap；正常终止才去掉后续项。Actor 更新读取的 Q 不反向传播到 Critic。
不增加辅助损失、规则评分或探索奖励。本轮不改折扣、熵或代价权重。

Actor 参数结构可以保持不变，不等于完整旧检查点可以无条件恢复。
新 Critic 头、读取描述及回放字段需要显式版本。旧经验若缺描述，只有在同版本场景、完整旧 K/动作/传感器配置可精确重建时才可转换，不能用当前地图补旧状态。
需要保留旧 Actor 权重的迁移与从头训练消融分别执行；本次未迁移、未清空经验、未恢复训练。

## 6. 验证结论

独立原型位于已忽略目录 `training-output/critic-audit-20260918/`。

- 46 个记录条目：42 PASS、4 EXPECTED_LIMITATION，全部断言通过。
- 24 张随机小地图 × 8 朝向，共 192 次，与独立闭方格射线几何 oracle 逐格一致；含 30/90/180/360°、安装偏航、多个分辨率、无效测量、UNKNOWN 和遮挡。
- 项目真实生成的月表/洞穴各一张，名义尺度 40 m；原生高程派生、传感器和覆盖参考共 192 次候选朝向检查，静态 g* 与一次名义同位姿测量的新增参考面积一致。
- 只读查询的置换、增删其他查询、世界平移、梯度和源位置区别通过；四个站位、2/8 m 范围的合法距离与独立 SciPy Dijkstra 一致。
- 原有模型/SAC 测试 23 项通过。原型小网络验证的是接口与梯度，不是训练后的 Q 正确率。

四个保留局限：区域同覆盖比例不同方向余量；终点零值但途中转向有观测；名义视域不保证到达容差下同样观测；双向查询插入会改写骨架表示。

单线程 CPU 的 warm-cache 静态 g* 计算：8/16/32 位置 × 8 朝向中位数约 9/18/37 ms，0.2 m 分辨率、10 m/90°。
只测静态面积计算，不含位置支持搜索、真值图构建、网络编码、ROS 或完整训练吞吐。不得由此宣称大图端到端预算已通过。

尚未验证：正式连续位姿接入、新 Critic 整体实现、训练后价值排序、SAC 三组消融、导航控制闭环、100～300 m/公里级真值图性能、Humble/Orin/DDS/实车。

## 7. 创新与下一步边界

基线采用候选位置对应；定向静态剩余可见面积是可单独消融的改进，创新性仍需专门查重。
只读位置查询是为了语义稳定与工程简洁，不宣称通用插值或图读取为原创。

完整效果对照应固定新决策图、任务分布、奖励、更新预算和随机种子组，比较公共摘要、候选对应、候选对应加 g* 三组。
同时查看最终覆盖、任务耗尽成功率、首次任务新增观测路程、总路程和循环频率；零静态增益的必要回退必须仍可执行。
比较训练随机策略与部署贪心策略；只看 Critic loss 或一次成功场景不足以证明效果。

## 2026-09-19 实施边界

`PrivilegedActionContext` 保存唯一精确 XY、动作到位置索引、精确朝向序列、CSR 支持与合法距离、每动作 g*。
采集器在当前动作执行前和下一状态形成后分别冻结；回放核对 XY 和朝向顺序，不保存每动作射线位图。
Q 头读取测量动作特征、公共真值摘要、候选局部几何特征与 g*/100；Actor 不读取此数据。
正常真值 FREE 起点按正式 containing-cell 连接取支持；不以跨墙欧氏近邻填补缺失支持。
协议为 `candidate_truth_v1`，学习器为 `candidate_graph_sac_v2`；旧完整检查点不能自动迁移。
