# 月球极区 Blender 环境设计

## 目标

将 Blender 中现有的 120×120 米程序化月面升级为适合导航场景展示的月球极区高地：地表崎岖、撞击坑密集、岩石破碎且棱角明显，并包含一个永久阴影区（PSR）坑底。

## 范围与约束

- 采用混合方案：确定性 Python 几何生成，加一套本地 CC0 PBR 贴图细化材质。
- 外部资产只下载至 `~/CodexDownloads/lunar_navigation/blender/assets/`，不写入仓库。
- 保留 1 米 Blender 单位、ROS/Isaac Sim 友好的米制尺度和可重复的随机种子。
- 只重建 `LunarEnvironment` collection；不改默认相机、立方体和灯光。
- 不下载其它资源，不保存或导出 `.blend`，除非用户另行要求。

## 地貌

- 主坑：半径约 20 米，陡峭内壁、非均匀高坑缘、同向喷出物、岩石密集带；坑底保持不受直接照明，作为 PSR 近似。
- 次级坑：约 15 个，尺度和侵蚀程度不同；新坑具有锐缘，老坑更平缓。
- 背景：多频地形起伏、坑缘崩塌碎屑、稀疏小砾石和较大的散布岩块。

## 岩石与材质

- 使用多个不规则、扁平或楔形的程序化岩石原型，避免当前共享球状网格的重复感。
- 下载一套 2K、CC0 的岩石或地表 PBR 纹理，使用色彩、粗糙度、法线和高度图驱动月壤与岩石材质；颜色校正为冷灰色。
- 月壤和岩石均为非金属、高粗糙度；细颗粒主要以节点材质呈现，避免对象数量无必要膨胀。

## 光照与可读性

- 使用接近地平线的太阳角（约 1.5°），产生极区特有的长阴影。
- 主坑内部不配置补光，保持黑暗；坑缘和高地保留局部可见性，便于判断地形结构。

## 验证

1. 脚本通过 Python 语法检查，且不含下载、保存或导出调用。
2. Blender MCP 执行后确认主坑、次级坑、岩石原型、月壤材质和极区太阳对象存在。
3. 确认主坑底没有直接光照，并统计对象数量及名称范围。
4. 确认外部资产位于允许的下载目录，记录原始 URL、许可和 SHA-256。
