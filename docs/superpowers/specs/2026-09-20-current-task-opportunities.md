# 基于当前观测机会的任务耗尽

用户已确认：不推理未来潜在观测需求；区外绕行是许可，不构成排查区外未知的义务。本设计替代本试验分支的覆盖下界设计，复用现有工作树，正式开发线暂不切换。

## 职责

- 真值 E、实际累计观测 K、真实覆盖率 `|K∩E|/|E|` 保持原定义；80%/99% 是训练评估指标。部署端不获得 E。
- TaskAnalyzer 维护任务内已观测面积及当前观测机会。只允许当前原生已知可达集合 R 中的位置作为观测站位。
- GraphBuilder 继续完成净空优先选点、度量连边、观测补点、八方向收益和回退/区外连接。Actor/Critic、导航、跟踪和传感器真值模型保持现有职责。
- Runtime 和训练环境共用耗尽判据。决策预算仍是截断；碰撞和输入不可用不变成成功。

## 当前机会

1. 累计任务内未知中心为 D；它是当前未测量集合，不声称是可覆盖面积。只查询 D 与已测量透射空间或任务多边形外部相邻的边界，及 R 内未分类的中心；射线进入 D 必先接触这类边界，无需逐格查询未知区域内部。
2. 在传感器距离内，从 R 中寻找当前地图 B 未阻挡的实际射线，检查是否能观测 D。UNKNOWN 在这一步只是单次观测的未知内容，不产生可执行站位、不推断未来通道。
3. 对成功射线提取首个未测量中心，作为当前前沿接口，并保留 R 中的实际观测见证。按接口去重，使用同一传感器射线与八方向视野计算节点收益。
4. 接口可能位于任务外，但必须支撑从当前可达站位直接观测任务内未知的射线。单纯通向远处任务的未知区外通道不产生观测需求。任何区外面积均不计入覆盖奖励。
5. 无需遍历潜在移动组件、合并无限外部或估计剩余面积上下界。

图的观测补点直接在符合到达距离要求的 R 中寻找剩余接口的观测位置。TaskAnalyzer 给出的首个见证只说明机会存在，不能保证它没有被图的到达容差收缩。补点因此由 GraphBuilder 选择，保留既有净空基础选点、覆盖半径、连边和稀疏化规则，不依赖无关区外接口偶然带来的替代见证。

## 耗尽与起点

任务已有有效观测且当前机会为空时耗尽。已有任务观测之后的耗尽判断覆盖整个 R，不只看当前位置或相邻节点。已知地图输入不可用和图未能表示有效接口沿用原错误语义。

起点可能远在任务区外。累计任务观测为零且无直接机会时保持可决策，报告 `TASK_NOT_OBSERVED`；不新增强制接近控制器，仍由 Actor 使用任务多边形和已知可达图选择下一跳。若始终不能产生任务观测，则由现有决策预算截断，不声称任务覆盖达标。特别地，完全不可观测且从未观测的任务不能通过真值捷径在部署端认定成功。

`completed` 是有效输入下的 `exhausted`。删除覆盖下界、剩余面积上界及在线 coverage_target 参数，防止两个结束定义长期并存。完整回放恢复身份更新；旧 Actor 可用于冻结对比，但不将旧回放静默用于新终止语义。

## 验证与采用

- 区内机会、当前区外观察区内、无收益区外支路、未来未知绕行、已知区外绕行、封闭障碍、不可站立但可观察、90° 转向、区外远起点、不可用输入。
- 微型栅格上从全部当前 R 逐站位执行独立传感器观测，与机会有无对照；不再验证剩余面积上界。
- 固定月表/洞穴快照报告当前接口、当前观测机会、真实剩余面积、真实覆盖率、运行时间；两类量不强行等同。
- 既有历史目标通过同一原生导航/控制重放；正式规划证据为 PLAN_FOUND、outcome=0、has_reference 及活动 PathReference，并记录 GOAL_REACHED/碰撞。
- 运行相关包全套测试、隔离 Jazzy 构建/测试。Humble/Orin/实车为 NOT_RUN；本轮不宣称训练收敛或循环已消除。

所有旧实验结果保留在原提交及原产物中；本轮产物使用独立文件名，不复制检查点或重启训练。
