# 可调整运行配置实施计划

用户已确认：合法配置不与固定基线数值比较，朝向数量可调整，QoS和帧按实际支持验证，错误指出字段。
范围：独立工作树 fix/flexible-runtime-config；不合并/部署，不改碰撞和目标选择算法。

1. 能力加载器：新增合法降速/尺寸调整测试，删除运行时 ExpectedCapability 固定值比较；保留字段、数值、平台种类和运动学必要约束，返回详细错误。
2. 候选朝向：固定数组改有预算约束的动态集合，覆盖3/7朝向与无效输入；ROS参数完整传递。
3. 统一launch：允许合法QoS组合、支持自定义坐标系名称并沿输入变换、地图、状态、消息输出传递；不能仅删除launch门槛。
4. 参数生命周期：启动配置生效，不支持的运行中变更应明确要求重启，避免静默不生效。
5. 文档、静态测试、Jazzy独立构建和受影响包串行测试，保留失败与未验证边界。

实施与验证已完成，详见 [可调整运行配置](../../可调整运行配置.md)。11 包构建、1238 个包测试用例通过；314 项仓库选择集通过。两项旧仓库检查失败已在未修改集成基线复现并记录。用户于 2026-09-11 授权提交并合入集成主线，再从集成主线建立 Orin 部署分支。远程推送及设备部署未执行。
