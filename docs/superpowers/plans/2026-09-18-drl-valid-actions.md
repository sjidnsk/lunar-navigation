# 探索有效动作与折扣学习实施计划

目标：按用户已确认的修正方案，消除原地无变化动作，保留必要扫描和零即时收益绕行，稳定价值目标。
架构：GraphBuilder 唯一构建有效动作，Actor 与 Critic 使用冻结动作列表；导航、控制、覆盖和耗尽判据不变。
技术：现有 Python / NumPy / PyTorch / ROS 2 Jazzy。在现有隔离 redesign 工作树实施。
