# 净空优先决策图与单线训练基线

## 采用决定

采用先前对照的 B 版：基础选点按当前观测导航 FREE 域中到非 FREE 栅格中心的距离降序，
平局按 y/x 排序。原型对比见[历史报告](2026-09-19-drl-clearance-order-probe.md)。
该对比支持改善节点位置、减少边界节点，并保留空间覆盖与任务观测机会；没有证明训练必然收敛。
C 版的观测补点平局净空排序没有显示额外收益，本次不采用。

专项分支从 `dev/drl-exploration` 派生为 `test/drl-clearance-baseline`，验证后回到开发线。
原有导航净空代价2.0、保留净空的路径简化器、公共控制器不变。

## 实现边界

- `metric_graph.clearance_order` 只负责基础选点优先序。距离场用全部观测导航 FREE 格，
  不是任务边界、真值地图或只有起点连通部分；候选仍只取起点可达格。
- 在全部 FREE 格的包围框内加一圈非 FREE 格计算距离场，与全图加边界的距离场等价。
  不移动节点、不添加硬净空门槛、不增加状态缓存，不把非连通自由格改成障碍。
- 原生 `cover` 接收优先序，保留有效旧节点，仍按2 m合法路径覆盖补点。
  8 m局部连接、1.2稀疏化、观测补点和实际位姿锚点保持原规则。
- 窄通道、必要观测点及锚点仍可能靠近边界，不能把净空排序解释为全体节点最小净空保证。
- 完整检查点的 `graph_geometry.base_order=clearance_desc_yx_v1` 标明新规则。
  旧行列顺序完整检查点不能静默续训；旧产物保留。Actor张量结构和 `task_graph_v3` 不变，
  旧Actor可供明确标识的离线诊断，但本次基线从新模型、新回放开始。

## 单线基线协议

这是一条持续学习的 C=0 策略，不是冻结随机Actor，也不是继续六组配对实验。

| 项目 | 设置 |
| --- | --- |
| 奖励 | `ΔA/100 - 0.002×ΔL - 0.005×ΔΘ/π - 0.001`，不变 |
| 学习 | gamma=.995，目标熵因子.10，alpha上限1e-4；温度仍按原规则学习；lr=1e-5 |
| Actor | C=0原分数，网络正常更新；Critic正常更新 |
| 采集 | 8环境，30倍目标倍率，0.2 m/s，10 m/90° |
| 批量 | batch64、microbatch16、预热1024、更新比.25，不变 |
| 训练地图 | 保留既有课程；本次累计10k范围内为40–80 m月表/洞穴小图，不改课程边界 |
| 观察点 | 累计约2000、5000、10000条转移；共10k，不是每阶段重新训练10k |
| 固定评估 | 月表与洞穴各一张40 m地图，seed=2026091901，512决策预算；所有阶段完全相同 |
| 评估方式 | 最新learner Actor联合argmax，无学习；与训练地图种子命名空间分离 |
| 保存 | 30分钟覆盖保存；阶段切换正常保存、关闭环境，续训恢复模型/优化器/温度/回放/课程，环境重开回合 |

`baseline_experiment` 只编排现有训练、导出、评估CLI，不修改SAC损失和训练调度。
几何诊断统一放在 `evaluation.GeometryMetrics`，原Actor配对实验复用同一实现。
固定评估保存覆盖、路程、80/99达成、耗尽、截断、零收益比例、最长零收益段、两点循环窗口和失败。
世界坐标A-B-A-B-A连续四次零收益、位置容差0.05m计一个循环窗口；不将必要回退一概视为错误。

达到预算、碰撞、异常均保留。单种子、两张小图只用于观察学习趋势，不能据此认定99%成功率、
大图泛化或收敛。既有三种子Actor配对实验不再自动启动。
