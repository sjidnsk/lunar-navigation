## 2. 经验说明问题已经不是“再多采集一点”

保留经验中 88.7009% 的动作没有新增任务面积。全部动作路程中位数 0.1839 m，零增益动作中位数 0.1800 m。
最长连续零增益序列为 512、498、480、463、456 步。
保留经验包含 16 个预算截断，0 个正常耗尽；其余回合不是完整回合。不能据此宣称训练全历史没有完成过场景。

逐条按正式公式复算奖励：

`r = ΔA/100 - 0.002 ΔL - 0.005 ΔΘ/π - 0.001`

最大误差 5.55e-17，未发现奖励符号、单位或记录不一致。
当前 alpha=4.22256e-5，163 状态的最大实测 alpha×H 约 7.72e-5，低于固定步代价 0.001。
因此早期“大熵奖励足以直接支付循环成本”的解释不适用于本次样本；这不代表过低温度没有副作用。

## 3. 已验证的 Actor 恢复困难

一个月表停滞状态（seed 87019971607003277，小样本 index 10）：

| 指标 | Actor 当前最偏好动作 | 当前双 Critic 最小值评分的第一名 |
|---|---:|---:|
| 候选目标 | 原地转向 | (11.9450, 26.9450, 270°) |
| 动作概率 | 0.742803 | 3.356e-9 |
| Q | 0.540618 | 0.556475 |
| 原生真值静态剩余任务面积 | 0 | 17.24 m² |

17.24 m² 是对动作前冻结 K 的名义终点视域计算，不是执行完整导航后的实测奖励，也不证明 Q 的完整排序最优。
但这个状态确实证明了：当前 Actor 没有实现当前 Critic 所要求的动作排序。不能把全部问题推给 Critic 或不存在候选。

对该状态固定全部 Q、相同 Actor 初值、新建 Adam、lr=1e-5，各自独立更新 300 次：

| 设置 | 最佳 Q 动作最终概率 | 是否成为 argmax |
|---|---:|---|
| 正式 SAC Actor 损失，原 alpha | 4.59e-7 | 否 |
| 相同损失，alpha=0.001 | 8.78e-7 | 否 |
| 相同损失，有界分数 C=10 | 0.737915 | 是 |
| 相同损失，有界分数 C=5 | 0.407528 | 是 |
| 前向 KL/交叉熵拟合冻结 Boltzmann 分布，仅诊断 | 0.835013 | 是 |

有界实验使用 `C*tanh((logits-mean(logits))/C)`，不改变原始动作排序；它是对现有头的受控重参数化，**不是完整复现论文 Pointer 头**。
C=5 在另一个初始最佳动作概率约 9.49% 的控制状态上反而造成更大 Q 遗憾，不能认为限制越紧越好。

当前离散 SAC 的 Actor 损失是 `Σ π(a)[alpha log π(a)-Q(a)]`。最佳动作初始 logit 梯度约 -6.19e-11，而其他动作最大绝对梯度约 1.32e-3。
枚举所有动作并不消除这个概率加权效应。曾被压到极低概率的动作，即使 Q 后来变高，也很难重新获得概率。
有界分数能在这些固定状态上恢复选择，证明无须增加网络容量或引入任务距离场就可能改善这一机制；尚未证明长训与部署成功率改善。

前向 KL 只作诊断，不推荐直接替换非对称 SAC：对 Actor 看不到的隐藏状态，`E[softmax(Q(s*,a)/alpha)|o]` 一般不等于 `softmax(E[Q(s*,a)|o]/alpha)`，会改变部分可观测下的优化语义。

## 4. 联合熵掩盖了位置选择塌缩

将联合动作概率按位置汇总，严格使用 `H(v,theta)=H(v)+H(theta|v)`，不修改策略：

- 同一 index 10 的位置最大概率约 0.999985。
- 位置熵约 0.000179，条件朝向熵约 0.5701。
- 现有联合熵目标为 `0.1 log(18)=0.2890`。

所以温度调节看到“熵已经足够”，而位置选择几乎确定。12 个诊断状态中有多个位置最大概率接近 1，但条件朝向熵仍为 0.5～1.54。
这只是选取停滞状态的诊断，不是全部训练状态的比例估计。

论文每个动作是一处位置；项目一处位置展开多个朝向。直接把 `log(位置数×朝向数)` 当作同一种探索强度，物理含义不同。
必须分别监测位置熵与条件朝向熵。是否分别调节熵权重应单独消融；本轮没有为它添加生产温度控制器。

## 5. 折扣和代价确实可能改变任务目标

精确组合实验覆盖：路程 20/80/200/600 m；分段 0.2/2/4/8 m；末端收益 1/10/50/100/500 m²；gamma 0.99/0.995/0.999/1；零增益循环单步路程 0.2/1.6 m。
假设通道途中无新增、无转角，最后揭开剩余面积并终止。所有返回值同时由显式求和及倒序 Bellman 递推计算，一致。

每种 gamma 有 160 组。无限循环优于完成路线的组数为 34、22、0、0；这是选定组合的计数，不能外推为真实地图失败率，也不能证明 gamma=0.999 普遍充分。

gamma=0.995 的一个严格反例：

- 反复走 0.2 m，单步 r=-0.0014，无限折扣回报 -0.28。
- 走 200 m，每步 2 m，末端新增 1 m² 后完成，回报 -0.38814。

于是当前目标数学上偏好无限循环，即使价值估计完全正确。这是后期远处少量残余面积的目标风险，不是声称两场实测循环就由这个反例引起。
实测转向代价常常较大，不能只用 0.2 m 路程估算真实循环成本。

同样走 80 m、末端新增 50 m²：0.2 m 分段回报 -0.17463，4 m 分段回报 +0.28288。区别来自固定步代价和按决策步折扣，而不是物理路线变化。
取消固定步代价仍不能消除按步折扣的差别；gamma=1 且无固定步代价时，本模型同一物理轨迹回报与分段无关。

但不能只把 gamma 改成 1：对持续循环状态，一步 TD 的值偏置不再通过折扣收缩；在缺少完成样本时，训练可能更难锚定值函数。
把预算截断改成成功/普通 terminal 也不是解法：会把“拖到预算结束以少付代价”引入目标。本轮正式 bootstrap 语义未变。

## 6. 当前 Q 的证据边界

163 状态中有 69 个后续连续 64 步真实记录全为零增益。
其一步 TD 残差绝对值中位数约 0.02036；当前 Q 与“记录的 64 步回报 + 当前网络末端 bootstrap”的差值中位数约 +0.34575。
说明小的一步误差不能替代长时序一致性检查。

这些记录由不同历史 Actor（约 16288～18512）采集，而评分来自 18547；长窗口计算不含沿途熵且属于 off-policy，因此这不是无偏的当前 soft-Q 误差估计，不能直接作为新 TD 标签。
最准确的结论是：存在长期估计不一致的诊断信号，需要在固定策略和新图上进一步做回报校准。

将真值已观测位图替换成全已观测/全未观测，会改变当前 Critic 的绝对值和部分动作排序，说明它并非完全忽略真值。
这些是物理上不一定一致的敏感性输入，不能证明原公共摘要充分，也不能把“只读候选对应”的改进宣称为已经解决问题。

## 7. 最新策略的正式导航闭环

场景固定 seed 2026091501、名义 40 m，传感器 10 m/90°，速度上限 0.2 m/s，目标仿真倍率 30，Actor/Q 冻结为 18547。
每类场景仅执行 81 个诊断动作，预算仍为 512，因此**不是完整回合完成率测试**。

| 场景 | 初始覆盖 | 第 81 步覆盖 | 零增益动作 | 导航结果 |
|---|---:|---:|---:|---|
| 月表 | 5.173% | 12.934% | 57/81 | 81 次 GOAL_REACHED |
| 洞穴 | 14.784% | 28.472% | 73/81 | 81 次 GOAL_REACHED |

月表尾段在同一位置的 270°/315°之间转动。洞穴尾段在约 0.2 m 相邻点往返。
本轮未出现导航失败或碰撞报告，说明这些循环不是本次目标执行失败的表现；不据此宣称导航器没有任何问题。

唯一干预：第 65 步若当前允许动作中存在正的真值静态收益，就选一次最大静态收益候选。月表当时没有，未干预；洞穴选择一次原地观测，实际新增 0.04 m²，随后交还 Actor，仍进入微小往返。
这说明单次解困/贪心观测不等于长期策略修复。由于是微量收益且含运动成本，该动作奖励仍为负值，不能声称它本身就是最佳长期动作。

## 9. 推荐设计与修正顺序

结论不是单一根因：细碎动作导致物理探索效率差；概率塌缩导致 Actor 难以跟随改善后的 Q；联合熵会把朝向随机性误当作位置探索；按步折扣与轻循环成本存在任务目标冲突。公共真值摘要是否是主导瓶颈仍需训练消融。

推荐保持以下职责：

1. **决策图**落实已经确认的 2 m 覆盖、8 m 局部连接和 1.2 路程伸长规则，表达真实观测机会与必要转移。移动零收益和任务外节点仍保留，不用禁回头补丁。
2. **Critic**落实已经确认的候选位置对应与定向真值静态剩余面积，减少动作与真值空间对应的学习负担；仍评价实际动作的长期回报。
3. **Actor**首选沿成熟注意力选择机制约束分数幅度，保留枚举离散 SAC。此轮受控证据支持先验证有界分数；不直接改前向 KL、行为混合或硬概率下限。
4. **熵**先分别记录 H(position)、H(heading|position) 和未选高 Q 动作的概率。验证有界 Actor 后，再单独比较联合熵与按位置/朝向分解的熵权重，避免一次同时改变损失、熵上限、学习率。
5. **奖励/折扣**保留按固定物理单位计量，不用场景真值总面积给 Actor 或按面积缩小大图奖励。先在新节点尺度下复核代价与延迟；当前 .995 不应直接视为覆盖优先目标的最终参数。对 .995/.999/1 分组，比较必要回退、远处收尾、正常耗尽和循环，不仅看平均覆盖。

论文 gamma=1 对完整探索路线的物理代价更自然，但必须同时验证值学习稳定性；.999 在本次有限反例集中没有偏爱循环，不构成通用保证。
新增面积优先、路程次要是任务优先级，固定权重的标量奖励只是折中，不能宣称它严格保证 99% 或穷尽探索。

建议顺序是明确的单因素对照，不是全部开关一起打开：新图基线 → 候选对应 Critic → 有界 Actor → 折扣/熵对照。
冻结回放的恢复实验已经表明“现有 Actor 再多训练一些”并非稳妥方案；也不意味着每项设计修改都必须丢弃所有可兼容参数。
没有把前沿基线、额外检查或大规模实验作为启动新设计的准入门槛。
