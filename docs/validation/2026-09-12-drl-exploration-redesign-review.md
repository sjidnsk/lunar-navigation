## 3. 定义的有限穷举检查

使用独立的 Python 整数位图小模型检查面积/完成定义，未调用或实现项目新算法。

范围是 3×3 有界格，中心起点真值为 FREE 且已知；其余八格各自可以是真值 FREE/BLOCKED，每格又可已知/未知。对每一种真值和证据组合，分别测试全图任务、右列任务及中心单格任务。

等价复现步骤：

```text
for truth_free in 256 个包含中心的自由掩码:
    R = 四连通(truth_free, 中心)
    E = R 并 (R 的四邻域中真值 BLOCKED 的格)
    for known in 256 个包含中心的已知掩码:
        B_known = known 交 真值 BLOCKED
        P = 四连通(非 B_known, 中心)
        U = 非 known
        for T in [全图, 右列, 中心]:
            W = T 交 U 交 P
            missing_reference = T 交 E 交 U
            assert W 非空 or missing_reference 为空
```

实际输出：

```text
cases: 196608
completed_cases: 76784
violations: 0
reverse_counterexamples: 2816
```

含义：在这些真值一致的有限格例中，“在线完成却遗漏参考格”没有出现；反向命题有 2,816 个反例，因此正文不能写成 `C*=100%` 与在线完成完全等价。

这个结果只是小模型的逻辑检查，不证明压缩瓦片实现、观测模型、策略可达性、导航能力或实机场景正确，也不替代正文第 17 节的实现测试。

## 4. 前沿相关性检查与修订

审查发现，仅写“未知侧可在潜在图中通向任务未知”会把通过已知根区域绕回的无关分支也关联到任务。正文第 8.2 节已明确：移除当前已知自由根分量，再计算未知侧与任务未解决区域的关联。

独立小例：`#` 为已知障碍，`.`/`R` 为已知自由，`?` 为未知。任务只包含中间行最右格，R 为平台。

```text
#####
..R??
##?##
```

按行优先索引，全部前沿接口是 `(7,8)`、`(7,12)`；应用修订后，仅 `(7,8)` 与任务有关。检查通过。底部未知不能因为可经已知 R 返回右侧就变成任务必须探索的分支。

外部连成一大片未知时，相关性仍可能宽泛；这是保守信息状态，不以距离阈值或虚构障碍把它消掉。

## 5. 其他内部一致性修订

- 任务几何保留角点和边向量输入，避免仅用质心/包围盒丢失凹多边形区别。
- 局部目标缩短后保持 gamma=0.999，未把远期收益再按 0.99 快速衰减；大场景效果仍需测量。
- 更新债务的 256 是派发背压阈值；已经在执行的最多八个目标可以正常收尾，不截掉其经验或更新额度。
- 没有可用下一动作且非业务终止的样本，不把空 soft value 置零；记录丢弃并恢复环境。
- 主训练继续完整 ROS 导航闭环，没有静默替换为传送/真值路径环境；独立验证也不长期占用 E0。
- 训练预算按局部动作尺度重设，未直接沿用旧 256 次宏动作预算；训练上限始终是截断。
- 真值参考、任务相关性与奖励使用不同的明确集合；排除未知、降低分母或请求过某个目标均不产生覆盖奖励。

## 7. 2026-09-13 奖励尺度与批注复核

本次按用户要求将设计目标改为 8 环境、20 倍仿真。保持 0.2 m/s、0.05 仿真秒积分、2 Hz 仿真观测、1,800 秒墙钟保存；没有修改旧工作树的运行配置或启停训练。20 倍是调度目标，不是性能实测结果。

批注中的 95% 是参考覆盖评估里程碑，任务仍执行至 `W_t=∅`：剩余任务格要么已知，要么被已知阻塞证据与平台隔开。任务外未知仍可绕回时不能提前排除；无界外部条件下也不能承诺任意场景都能由有限观测证明完成。达到里程碑、在线完成、失败和截断分别记录。

输入/网络核对：旧实现实际包含 8 通道局部栅格、122 维节点、13 维上下文和 GRU 时序编码；本设计改为节点 12 维、边 2 维的稀疏图、多边形角点/边向量、12 维上下文及 6 维朝向特征。信息源仍是任务、平台位姿和导航地图，真值分母不进入 Actor/Critic。图和实际轨迹/方向访问记录承担显式空间记忆，不能把取消 GRU 等同于已证明状态完全可观测。局部位置头和条件朝向头共同确定下一位姿，原导航继续负责路径与执行。

### 7.1 奖励结构与原文依据

[ARiADNE 第 III-A 节](https://arxiv.org/pdf/2301.11575) 使用观测前沿数量奖励、距离代价和完成奖励，其尺度系数分别为 `1/50`、`1/64`，完成奖励为 20。它支持这一类分项结构，但不能证明本项目的面积单位、局部步长及五倍成本正确。

[HEADER 的问题分析和第 V-A1 节](https://arxiv.org/html/2510.15679v1) 指出：信息增益和路程的手工加权可能偏离全局完成目标，长通道回溯尤其缺少即时正反馈。其专家奖励不是本项目已采用的能力，也不据此添加专家规划依赖。

[SAC 的 Reward scale 分析](https://proceedings.mlr.press/v80/haarnoja18b/haarnoja18b.pdf) 说明环境奖励尺度与最大熵策略的随机性有关。下面的一致缩放判断来自 SAC 目标的代数分析，不是论文直接推荐按本项目任务面积归一化。

### 7.2 五倍成本的数值反例

假设从当前状态起，必须沿已知通道前进 1,000 m 才能确认最后 1 m² 并完成；每次前进 2 m，共 500 步，中途没有新增面积。不考虑额外转弯、碰撞、熵和模型误差。另一个合法但不完成的策略是在已观察位置反复交替旋转 30°。

令 `g=0.999`、`A0=78.53981633974483`，从当前状态开始的折扣回报为：

```text
route = -(w_L * 2 / 10) * (1 - g**500) / (1 - g)
        + g**499 * (5 + 1 / A0)
spin  = -(w_theta / 12) / (1 - g)
```

| 路程权重 / 转角权重 | 完成通道回报 | 持续转向回报 |
|---|---:|---:|
| 0.05 / 0.005，上一版候选 | -0.893553 | -0.416667 |
| 0.01 / 0.001，建议比较基线 | 2.255416 | -0.083333 |

Python 双精度计算已复核。反例显示前一组权重可能奖励不完成的行为，即使不计熵也存在该问题。它是满足上述假设的目标冲突例子，不是当前模型轨迹实测；后一组只解决此例，不证明对所有场景正确。采样截断保留自举的设计也不能靠截断本身消除这种价值排序。

原候选中，走 1 m 的代价相当于确认约 0.3927 m² 的奖励；基线约为 0.07854 m²。应将路程、转角、完成奖励、折扣和熵作为一个整体评估。地图尺度缩放不会自动解决这些相对权重问题。

### 7.3 不同地图大小的处理

- 保留传感器尺度作为建议的训练基线：`ΔA/A0`、`ΔL/R`、`ΔΘ/(2π)`，相同物理进展具有相同局部奖惩。
- 不单独改成覆盖百分比奖励后沿用其他权重。10,000 m² 和 1,000,000 m² 两任务中，同样新增 10 m² 若除以任务面积，分别只奖励 0.001 与 0.00001，而相同路程仍扣同样分数。
- 若为了比较而要求每张图满分接近一致，应区分评估指标和学习奖励。完成率、参考覆盖比例天然可比；路程按尺度/地形分组，并补充单位参考面积路程。后者仍受拓扑、量程和起点影响，不表示不同难度场景完全等价。
- 若后来确需每回合一致缩放 `r'=s*r`，则所有环境奖励项均缩放，SAC 使用 `α'=s*α`；目标熵的无量纲定义可以保持。对固定场景的任意策略，其期望 soft return 同比缩放；共享网络的多任务采样权重、梯度尺度及优化过程并不因此完全等价。
- 保留完成奖励不缩放、只缩放稠密项，是一种重新设计目标的选择，不能称作中性数值变换。在线变化的可覆盖面积估计不作为分母。

当前建议是保留物理尺度、撤回五倍成本已合理的暗示，以 0.01/0.001 开展基线比较；没有加入 PopArt、专家教师、循环黑名单或新的准入流程。大小图的长程问题还与按局部决策折扣有关：`0.999**500≈0.6064`，`0.999**5000≈0.00672`，仅归一化面积不能消除远期收益衰减。

本节证据范围是原文核对、旧源码读取、公式量纲与数值检查、设计文档检查。新奖励训练和对照实验仍为 `NOT_RUN`，不能据此宣布权重调优完成或 20 倍闭环已达成。

## 10. 实施前复审（2026-09-15）

用户确认公共控制器加轻量运动学平台，并授权审查后实施。审查基线为 `0ea4acd`；核对原生 `MeasureLocalElevation`、持久高程地图、FineCellEvaluator、ROS 适配与本版设计，另进行了独立只读设计审查。

发现并在设计中收口的两项关键问题：

1. **分类支撑与遮挡不闭合。** 原生 FREE 需要3×3邻域，BLOCKED 可能由一个陡升邻居提前判定。在真值 BLOCKED 上停止的射线可能只看到墙内侧平地，永远看不到使其阻塞的邻居。因此不能把仅回传中心高程与逐位姿有效分类并集混为一谈。采用有效中心地形测量近似，裁剪中心高程及原生坡度/起伏/正向高差；地图生产者仍执行同一分类/足迹派生。邻居真值不发布，Actor输入不变。原生 height-only 现场路径仍保留；有效测量和中心高程同版本融合，支撑不全不伪称完整。
2. **相关性缺少观测站位见证。** 任务未知格不是运动节点；先找可能看到需求的站位，再用导航可通行关系反推入口。视线使用固有遮挡，运动使用足迹状态；到达已知可达域停止扩散。见证站位交给图构建器保留，实际位姿单列锚点，避免窄孔、采样遗漏及“原地”动作平移。存储域外保留UNKNOWN分量。

SAC公式未发现符号错误，补齐 TD/Actor/温度梯度隔离及完整batch更新顺序。学习率、Polyak、课程里程和上下文标度等工程初值在实施清单中固定，不增加启动准入条件。

修正方向已由独立审查确认能消除封闭墙反例；后续必须以对应回归测试和真实导航闭环验证，文档审查本身不构成实现或训练通过。实施分为原生测量、地图导出、传感器/参考、任务图、SAC、回放恢复、ROS运行器、异步训练入口、综合验证九项，见[实施清单](../superpowers/plans/2026-09-15-drl-exploration-redesign.md)。
