## 实施结果和职责

| 模块 | 当前职责与变化 |
|---|---|
| `metric_graph.py`、`native/graph.cpp` | 原生有界 Dijkstra，八邻接且不穿角；2 m 路径覆盖、8 m 局部候选连接、1.2 贪心 spanner |
| `graph.py` | 保留有效世界基础节点，实际锚点接入、可执行站位的观测补点；去掉细门户/MST/19 邻居中转；不按区外、访问过或零收益屏蔽移动 |
| `decision.py` | 组合任务分析与图表示；无法表达接口时返回非耗尽的不可用状态，不伪造探索完成 |
| `privileged.py` | 仅训练侧持有真值地图，初始化静态骨架，每状态冻结候选局部支持和定向 g* |
| `contracts.py`、`batch.py`、`replay.py` | 唯一 XY、精确朝向顺序、动作映射、CSR 支持/路径距离和 g*；场景图共享，不持久化每动作射线位图 |
| `model.py`、`sac.py` | 每个 Critic 独立保留测量分支与真值全局摘要，新增候选只读局部几何汇聚和 g*/100；同位置八朝向共享位置读取 |
| `ros_env.py` | 执行前生成当前描述，完成观测后独立生成下一描述；真实执行增益仍计算奖励 |
| 配置/导出/恢复 | 更新协议并使用独立输出目录；保留旧文件，明确拒绝旧完整恢复 |

Actor 网络参数结构、奖励、gamma、熵、导航器、公共控制器和运动学模型均未因本次任务调整。传感器默认 10 m/90°，8 个环境、目标倍率30、平台0.2 m/s、batch64/microbatch16、每1800秒保存保持不变。

真值静态收益 g* 不是奖励，不删 Actor 动作，不决定耗尽。参考格的欧氏所有权仅用于背景面积特征汇总，候选局部支持使用合法路径距离，不能跨墙取直线近邻。

## 审查发现与处理

1. 同 XY 的不同朝向起初未绑定到冻结描述。补齐 float64 朝向序列并精确核对，测试交换朝向后旧描述被拒绝，重新构建收益顺序正确。
2. 初稿先补点再收缩已到达站位，可能漏掉仍可执行的远见证。最终按实际锚点和未到达基础节点建立初始可见并集，再从未到达 W 贪心补点；没有增加后置修补流程。复现站位 `(1.1,0.7)` 现在可选，遗漏接口归零。
3. 世界节点保留限于同物理格网。整格原点重索引保持节点，非整格相位、epoch或分辨率变化重新建立基础覆盖。

## 碰撞个案

探针保留 seed=`87019971607003160`、洞穴40 m、第三次决策的失败记录：目标 `(-24.7,5.3,π)`，实际停止 `(-25.606649,6.806758,2.322082)`，本动作行驶0.14 m后运动学平台拒绝一次不满足原生 M 扫掠连接的运动。计数中保留为 `COLLISION`；没有关闭碰撞检查、扩大容差或增加奖励惩罚来掩盖它。

在隔离 Jazzy domain202 按该回合三个已保存目标重放，复现 `GOAL_REACHED → GOAL_REACHED → COLLISION`，无需随机策略或学习更新。失败动作的决策图边长2.141642809 m，真值不穿角最短合法距离2.141642782 m，两者吻合。正式规划器返回 `PLAN_FOUND`，`start_patch_used=false`；参考线首段为 `(-25.70095065,6.91022785) → (-25.1,6.3)`，整条参考折线按0.1 mm采样并进一步按全部栅格边界精确分段，未发现非FREE区间。

公共控制器倒车命令约 `v=-0.2 m/s, ω=0.0306344 rad/s`。实际运动从格(69,194)趋向(70,193)，终点格FREE，但连续弧线进入侧格(69,193)的BLOCKED区域；1001点子采样也观测到该进入过程。相对参考线横向偏差约5.413 mm，候选段实际进入BLOCKED格约0.481 mm，因此不能把碰撞解释为单纯保守的对角检查。**本例定位到参考线边界余量与实际跟踪误差的执行问题，未发现新图跨墙连接。**未检验旧历史版本是否同样复现，未修改控制器或规划器来声称已修复。

证据为诊断目录 `collision-diagnostic.json`。此残留问题意味着本轮不能声明“所有探索执行均无碰撞”；后续处理应属于导航参考/控制跟踪与可通行边界的职责，不能靠策略动作黑名单或修改Critic收益掩盖。

## 限制与 NOT_RUN

- 正常 FREE containing-cell 起点的路径接入与正式原生规则一致。旧快照对 assumed-start 导出端点而不导出前缀路径成本，特殊前缀目前沿用欧氏初始成本，不能宣称该分支绝对8m边界/伸长已按真实前缀路程认证。
- 单层二维遮挡与原有高程派生可通行性保持现有职责，本轮没有建立高程视线模型。
- 长期收敛、反复两点循环的量化改善、完整探索耗尽/99%成功率、大尺度真实闭环：NOT_RUN。
- Humble、Jetson Orin、生产DDS/课题三接入、rosbag、实车：NOT_RUN。本地Jazzy ROS通信测试不替代上述证据。
