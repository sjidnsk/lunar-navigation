# 公共路径简化器：保持原路段净空

日期：2026-09-19。

## 改动范围

仅重构 `lunar_incremental_navigation_core/src/local/phase_aware_path_simplifier.cpp`，并补充该算法测试。输入输出接口、A*、地图派生、导航参数、控制器和碰撞判定保持各分支原有实现。本修复来自 DRL 开发工作树中的已验证改动，未合入其策略、模型、训练配置等其他差异。

同阶段内只接受合法且最小净空不低于原始对应子路径的直线替换。净空按连续线段到允许区域边界计算，不按栅格中心距离或离散采样计算。边界只在本次简化调用内生成，不增加持久地图层、后台更新、物理距离阈值或失败重试机制。

同向严格共线点先压缩，几何不变且继续检查通行性；其余捷径使用统一判据。原边净空缓存后始终作为比较基准，避免累计降低余量。起步临时补图阶段、未知禁入、窗口边界、取消和截止时间沿用原有语义。

本算法保证最小净空不降低，不保证净空分布逐点保持，也不为原本贴边的起终点创造新的执行余量。
