# 轮式局部规划净空代价权重标定

日期：2026-09-19。工作分支：`feat/clearance-cost-calibration`，基线 `9a5a23f7`。

## 结论与实施

推荐轮式默认 `clearance_weight=2.0`，沿用当前 `preferred_clearance_m=0.2 m`。
这是本次试验集上的工程折中，不宣称对任意地图最优。权重 0.5 已有明显改善；2 比 1 在部分密集障碍处保留更多余量；5～20 的新增收益很小，但个别路径绕行明显增加。

本分支在 `PlatformProfileFor` 设置轮式默认权重 2，足式默认保持 0。节点声明启动参数 `clearance_weight`，允许通过现有 navigation 配置覆盖，0 可关闭作对照。参数沿用原有启动后不可修改规则；只检查有限非负这一代价函数定义要求。没有增加地图层、额外可通行门槛、重试、控制策略或候选点规则。

此次没有合并到其他分支、更新既有安装目录或重启训练。实验库通过隔离子进程加载；部署需使用对应分支源码重新构建。

## 权重含义和职责

现有细地图的计算为：

```
d = max(0, 到最近固有危险格面积的距离 - 平台外接圆半径)
p = clamp(1 - d / preferred_clearance_m, 0, 1)
格代价 = 原坡度代价 + 原起伏代价 + clearance_weight * p
A* 边代价 = 边长 * (1 + 目标格代价)
```

未知格和固有不可通行格都会产生净空代价。当前轮式外接圆半径约 0.719 m，硬派生使用该包络半径；`0.2 m` 在本实现中是软代价影响范围，不能解读为在包络之外已硬性保证的 0.2 m。

权重 2 表示最贴边处每米额外最多计入 2 个等效米的代价；在 d=0.1 m 时额外计入 1，d≥0.2 m 时为 0。不含其他地形代价时，对应局部边成本倍率最多约 3。权重控制为了远离边界愿意付出多少绕行；不会扩大作用范围，也不会把原本可通行的窄通道改成不可通行。

地图负责生成硬状态和软代价，A* 负责累计代价选路，新简化器负责不降低原路段最小净空，控制器负责跟踪。简化器没有承诺保持整个路径的积分代价，所以所有路径质量指标都针对最终简化输出重新计算。

## 实验设计

只改变净空权重；固定新版简化器、平台几何、坡度/起伏权重、目标和地图。同一地图同一起终点配对比较 `0、0.5、1、2、5、10、20`。

1. **集成核心**：8 种合成场景 × 0.1/0.2/0.4 m 三种分辨率，共 24 张；另有月表/洞穴 × 40/80/300 m 场景尺度 × 两个固定种子，共 12 张局部地形快照。每张 8 组确定性采样的连通起终点，合计 36 张、288 组查询、2,016 个权重对照。
2. **应用核心**：实车和 Unreal 应用分支核心包内容相同，使用其独立编译库，对项目当前 0.2 m 分辨率的 20 张地图重复测试，160 组查询、1,120 个对照。其地形评估与集成分支有差异，因此分开报告；每个版本内部保持起终点固定，版本之间不把随机采样后的起终点视为完全相同。
3. **闭环**：固定此前失败洞穴 seed `87019971607003160`，两步相同前缀后执行旧失败目标和前方目标。7 个权重 × 2 个目标 × 3 次重复，共 42 次目标执行。采用已验证新版简化器、原有公共控制器和 0.2 m/s 轻量运动学平台，独立 DDS domain 230。

合成场景为开放区域、未知边界、矩形障碍、凹形障碍、双通路、窄通道、房间门洞和密集障碍。程序地形种子为 `2026091901/2026091902`；洞穴采样选择含低地通道的连通分量，避免将墙顶平台当作洞穴活动区域。

所有地图通过实际 `FineTraversabilityBuilder` 派生；用权重 0 和 1 的代价差构造其他权重，利用现有公式的精确线性关系，不重复实现距离场或搜索器。逐格核对 0/1 的硬状态完全相同。地图冷派生分别计时，规划使用真实 `WheelLocalPlanner` 和新版简化器，每组查询执行三次，报告其中位数。

合成快照约 32×24 m，程序地形截取 32×32 m 局部窗口；“300 m”指生成场景尺度，不表示本实验规划了完整 300 m 路径。没有用此结果证明 64 m 满窗口、1 km 全局滚动导航或 Orin 性能。

## 质量指标

- **路径净空**：参考中心折线到非 FREE 区域边界的距离。它包含可通行图的包络语义，不是车体到实体障碍的距离。独立 Python 连续线段几何核算最小值，全部结果满足简化后最小净空不低于原始路径。
- **贴边占比**：沿最终路径每 0.025 m 等距取样，去掉起终各 1 m，统计距边界小于 0.15 m（容差 1e-9）的比例，再对查询等权平均。0.15 m 只用于本报告统计，不是新增规划门槛；无法绕开的窄通道仍计入统计。
- **路程变化**：每组查询相对权重 0 的最终路径变化，分别报告均值与最大值，避免均值掩盖少数绕远案例。
- **时延**：规划与地图派生分别记录。测试时仍有其他本机进程，毫秒级差异不作严格性能排名。

## 结果

3,136 个权重对照均返回核心 `kPlanFound`（每组内部三次规划）。

以下为**应用核心、0.2 m 分辨率、160 组查询**：

| 权重 | 贴边占比 | 平均路程增加 | 最大路程增加 | 规划 P95 |
|---:|---:|---:|---:|---:|
| 0 | 14.02% | 0 | 0 | 4.58 ms |
| 0.5 | 9.16% | 0.172% | 2.31% | 4.66 ms |
| 1 | 7.41% | 0.193% | 2.31% | 4.75 ms |
| **2** | **6.89%** | **0.209%** | **2.31%** | **4.68 ms** |
| 5 | 6.84% | 0.227% | 3.65% | 4.71 ms |
| 10 | 6.84% | 0.227% | 3.65% | 4.76 ms |
| 20 | 6.81% | 0.263% | 6.84% | 4.64 ms |

权重 2 相对关闭减少约 50.8% 的贴边占比。相比 2，20 的贴边占比仅再下降约 0.08 个百分点，最坏绕行却从 2.31% 增至 6.84%。密集障碍示例中，权重 1 的最小净空为 0.100 m，权重 2 为 0.172 m；20 对这一案例没有进一步改善。

集成核心在同一分辨率上的结论一致：贴边占比 14.03%→6.89%，平均路程增加 0.209%，最大增加 2.31%，规划 P95 4.39→4.64 ms。三种分辨率合并时，权重 2 的最大路程增量约 8.61%，来自 0.1 m 场景；不能把 0.2 m 上的 2.31% 当成所有分辨率的上界。

0.2 m 地图冷派生均值：集成核心 99.09→105.09 ms，应用核心 121.13→128.82 ms。这里比较 0 与非零（1）；大于 0 后权重只改变乘数，不扩大邻域搜索。该冷派生时延不等同于增量更新时延。

42 次闭环全部 `GOAL_REACHED`、0 次碰撞，每个权重 6/6 到达；前缀也全部到达，诊断存在 `PLAN_FOUND` 和非空参考线，实际加载库路径已核对。**权重 0 也通过，因此不把旧碰撞修复归因于权重；原问题由新版简化器修正。** 42 次来自同一场景及相关状态，不能推导跨场景碰撞率，更不是带打滑的动力学或实车证明。

```bash
# CALIBRATION_ROOT 为本分支工作树；CORE_BUILD 为独立编译的核心包目录。
c++ -std=c++20 -O2 -DNDEBUG \
  -I "$CALIBRATION_ROOT/ros2_ws/src/lunar_incremental_navigation_core/include" \
  "$CALIBRATION_ROOT/scripts/validation/clearance_cost_probe.cpp" \
  -L "$CORE_BUILD" -Wl,-rpath,"$CORE_BUILD" -llunar_incremental_navigation_core \
  -o "$CALIBRATION_OUTPUT/probe"

# 按项目 scripts/drl/_run.sh 的方式清理继承 overlay，再 source Jazzy/DRL。
"$DRL_PYTHON" "$CALIBRATION_ROOT/scripts/validation/clearance_cost_sweep.py" \
  --probe "$CALIBRATION_OUTPUT/probe" --core-library-dir "$CORE_BUILD" \
  --output "$CALIBRATION_OUTPUT/verified-sweep"
# 应用版本另指定应用核心库及 --resolution 0.2，输出到 application-sweep。
```

探针临时二进制地图在转换为压缩 fixture 后删除，结果只保留所需路径和统计，不记录图像序列或训练回放。结果目录存在时脚本按完整地图续跑；更换代码或动态库应使用新输出目录。

证据范围：源码与本机 Jazzy、隔离轻量运动学闭环。Humble、Jetson Orin、TCP 动力学和实车均为 **NOT_RUN**。本次推荐是后续真实验证的默认值，不是固定安全距离保证。
