## 具体实现

| 职责 | 文件与行为 |
| --- | --- |
| Actor 分数参数化 | `model.py` 的唯一变换入口；`ModelConfig.actor_score_bound=0` 原样通过，C=10 使用 `10*tanh((z-mean(z))/10)`。均值只含当前状态的有效动作，保留梯度。 |
| 策略消费 | 采集、Actor 损失、TD 目标、导出和推理共用变换后的概率；Critic 不限幅，SAC 目标与损失不改。 |
| 诊断 | `sac.py` 增加位置熵、条件朝向熵、位置最大概率、原始分数跨度、饱和比例和原始分数梯度摘要。 |
| 配置与恢复 | 旧 v3 检查点缺失 C 时规范化为 C=0；不允许跨 C 直接完整恢复。旧图结构检查点仍不能冒充新图结构。 |
| 场景序列 | `training.py` 按 `(seed, env_slot, episode)` 产生地图，计数随检查点保存；异步完成顺序不改变槽位的地图序列。该实验固定小图，普通训练课程不变。 |
| 试验编排 | `paired_experiment.py` 单 GPU 串行运行各组，管理阶段、异常、固定评估、目录锁与恢复。 |
| 机制检验 | `actor_probe.py` 冻结候选 Critic 的 Q，分别量化变换即刻影响及继续学习影响；测试中途更换 Q 排序后的恢复。 |

完整续训保留模型、优化器、回放、调度等；环境从新的回合开始，并不声称恢复到停车瞬间。A/B 共享相同初始化参数与槽位地图序列，但策略导致的实际轨迹、回合完成数和异步收尾超额可能不同；记录实际采集量、更新数和初值 checksum。

## 配对计划

- 两组：`raw`（C=0）和 `bounded10`（C=10）。训练种子 20260919、20260920、20260921。
- 首种子两组分别到约 3000 转移，检查工程运行后分别续到约 10000；另两种子每组约 10000。共约 60000 转移，异步收尾会有少量超额。
- 每次 8 个环境，月表/洞穴，40–80 m，512 决策上限，目标倍率 30，速度上限 0.2 m/s，传感器 10 m/90°。
- batch=64，microbatch=16，预热 1024，更新比 0.25，学习率 1e-5，gamma=0.995，目标熵因子 0.10，alpha 上限 1e-4。
- 筛查评估：两类 40 m 地图各一个；最终评估：两类 × 两种尺度 40/80 m × 两个固定种子，共 8 个案例/组，均为 512 决策。
- 评估地图种子 2026091901/2026091902 与训练种子命名空间分离；冻结策略联合 argmax。后续不同传感器、大图泛化另测。
- 3000 转移是工程检查点，不凭早期覆盖率淘汰较慢的一组。单个评估失败保留并计入分母；训练基础设施失败或所有评估案例在首次决策前均报错才停止编排。

结果比较覆盖率、80%/99% 达成与对应路程、探索耗尽、零收益比例、最长零收益段、持续两点往返及碰撞。0.5 m 几何格重访/反向边只作辅助统计；持续两点往返另按 0.05 m 容差及连续至少四次零收益转移计算。必要回退和任务外绕行不被禁止。小样本短训只支持下一阶段选择，不是大规模泛化或收敛证明。

## 已执行的机制试验

使用新图/新 Critic 的 147 转移短试跑检查点（19 次更新），选择四个状态，有效动作数 16、34、61、78。每次拟合 300 次 Actor 更新：自然分数、将初始分数跨度放大到 40 两种设置；后者在第 150 次更换冻结 Q 的优选动作。所有训练采用原 SAC Actor 损失，Q 不反传也不写回回放。

受压制动作在更换 Q 后继续学习 150 次，最终概率如下：

| 有效动作数 | 原始分数 | C=10 | C=5 敏感性检查 |
| ---: | ---: | ---: | ---: |
| 16 | 4.19e-13 | 1.62e-7 | 7.2e-5 |
| 34 | 6.65e-24 | 2.22e-5 | 0.423 |
| 61 | 1.89e-17 | 2.90e-4 | 0.0347 |
| 78 | 1.40e-44 | 5.19e-4 | 0.0476 |

C=10 缓解了部分概率塌缩，但这些受控例子仍恢复缓慢；自然状态下 C=10 也没有一致优于原分数。C=5 只作为敏感性证据，不擅自替代已确认的正式对照。tanh 仍可能饱和；有界分数不是“必然能逃离循环”的保证。冻结的已学习 Q 不是最优真值，该试验不能替代导航闭环效果。

证据：输出根目录的 `mechanism.json`、`mechanism-c5.json`；输入检查点未改写。

## 操作与存储

以下命令从该工作树根目录执行。若任务已经运行，不要再次启动；目录独占锁会拒绝重复实例。

```bash
# 首次启动；已运行的实验不要重复执行
scripts/drl/compare_actor.sh --output-dir training-output/actor-bounded-20260919

# 正常中断后恢复相同计划，跳过已完成阶段
scripts/drl/compare_actor.sh --output-dir training-output/actor-bounded-20260919 --resume

# 看当前阶段和汇总
cat training-output/actor-bounded-20260919/paired-report.md
tail -n 24 training-output/actor-bounded-20260919/20260919/raw/current-stage.log
```

前台 Ctrl-C 正常保存退出。后台实例可读取 `paired-state.json` 的 `runner_pid`，确认对应命令后发送 `kill -INT <runner_pid>`；驱动转发给当前训练子进程，等待其保存，不再启动下一组。训练阶段每 1800 秒覆盖保存；固定评估无学习，不产生周期检查点。

每个 `<seed>/<arm>/` 保留一份 `resume.pt` 和训练器的当前策略文件；指标和 `current-stage.log` 各限制 8 MiB，评估只存 JSON 汇总，不录 bag/视频/逐帧地图或历史 checkpoint。导出用于评估的临时 Actor 用后删除。六组各自保留恢复文件以便复查；训练器每组仍使用现有容量限制，输出总目录不会由本任务自动清理。
